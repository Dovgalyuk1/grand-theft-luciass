# GRAND THEFT LUCIASS ($LUCIASS)

Fan-made Vice City meme-coin landing page — the gtaape.lol layout reworked around
a night-life legend, no build step, plain HTML/CSS/JS.

## Deploy
Push this folder to a GitHub repo, then import it on Vercel (Framework Preset: Other / static).
No build command needed.

## Before going live
Fill in `CONFIG` at the top of `script.js`: `CA`, `PUMPSWAP_URL`, `DEXSCREENER_URL`,
`TWITTER_URL`, `TELEGRAM_URL`. Everything else (copy-CA button, live Dexscreener chart,
all link buttons) picks these up automatically.
